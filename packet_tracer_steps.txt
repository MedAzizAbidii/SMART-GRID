PACKET TRACER QUICK STEPS

1) Build topology
- Add one switch (2960), one router (2911), one server, two PCs.
- Cable all endpoints to switch (copper straight-through).
- Cable router G0/0 to switch.

2) IP addressing
- Router G0/0: 192.168.10.1 / 255.255.255.0
- Server: 192.168.10.2 /24, gateway 192.168.10.1
- PC1: 192.168.10.11 /24, gateway 192.168.10.1
- PC2: 192.168.10.12 /24, gateway 192.168.10.1

3) Verify PT network
- From PC1 command prompt: ping 192.168.10.2
- If ping fails, fix cabling/IP/gateway first.

4) Run Python API on host machine
- In terminal:
  cd C:\Users\Batikha\Desktop\SMART GRID\smartgrid_simulation
  .\venv\Scripts\activate
  python run_demo.py

5) Verify host API in browser (host machine)
- http://127.0.0.1:8000
- http://127.0.0.1:8000/dashboard

6) Test from Packet Tracer PC browser
- Try: http://<YOUR_HOST_IP>:8000
- If blocked, this is often Packet Tracer host isolation/firewall.

7) Optional UDP forwarder
- Run in second terminal:
  python packet_tracer_client.py
- Default destination: 127.0.0.1:5000
- Change destination in packet_tracer_client.py if needed.

8) Manual attack injection test
- Open in browser:
  http://127.0.0.1:8000/docs
- Use POST /api/simulate/attack with bus_id=5, attack_type=fdia
- Confirm dashboard shows alert.

9) Demo fallback (if PT cannot call host HTTP)
- Keep Packet Tracer for network topology visualization.
- Use host dashboard for real-time smart-grid telemetry.
- Correlate PT events with dashboard alerts in thesis report.

10) Per-bus HTTP sender from Packet Tracer PCs
- Copy packet_tracer_data_sender.py to each PC (PC1..PC14).
- Set BUS_ID in each copy: PC1=1, PC2=2, ..., PC14=14.
- Keep API_URL as http://192.168.100.2:8000/api/grid/data if API is on Server.
- Run on each PC: python packet_tracer_data_sender.py
- Verify reception from host or browser:
  GET http://127.0.0.1:8000/api/grid/all

11) Silicon Apocalypse integration (Code Red bridge)
- Keep API running: python run_demo.py
- Send Code Red from a zone:
  python silicon_apocalypse_bridge.py --zone sector_a --motion --severity 0.85
- Clear zone to SAFE:
  python silicon_apocalypse_bridge.py --zone sector_a --safe
- Stream random events:
  python silicon_apocalypse_bridge.py --loop --interval 5
- Integration endpoint:
  POST /api/integrations/silicon-apocalypse/event
